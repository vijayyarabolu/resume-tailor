    1. Claude

    How the app reaches Claude

    The app was started with python -m resume_tailor demo, which always uses demo mode and its own demo folder. Start it with python -m resume_tailor serve to use a real key.

    Why a key, where to get one, and what it costs

    Anthropic doesn't offer a "Sign in with Claude" button for other people's apps, so this app talks to the Claude API with a key that belongs to you. Create one at platform.claude.com/settings/keys (sign up, add a payment method or credit under Billing, then Create key).

    The API is pay as you go. Claude Sonnet 5.5 costs $2 per million input tokens and $10 per million output tokens (pricing page, checked October 2026). One resume takes 1 to 3 calls of about 10,000 tokens in and 5,000 out, so it costs roughly 7 to 20 cents. If you make 100 resumes a month, expect something like $7 to $20. Haiku 5.5 is about a twentieth of that, Opus 5.5 about double. New accounts sometimes get a small trial credit; there is no ongoing free tier.

    Without a key, everything else still works: the queue, PDFs, checks, Drive and the demo mode. New resumes simply wait in the queue until a key is saved.

    Uses the Claude Code command line tool and whatever account it is logged in with (a Claude subscription works). Install it from claude.com/claude-code, then run claude auth login once in a terminal.

    Demo mode never calls Claude. A resume keeps your bullets as they are and gets the job's keywords you already own added to Skills, then goes through the same PDF and checks. Good for trying the app and for the tests.

    2. PDF engine

    Every resume is measured against your base resume drawn by the same engine, so line lengths and page breaks are judged the way the PDF will look. LibreOffice: libreoffice.org, or sudo apt install libreoffice-writer / brew install --cask libreoffice. The checks also need poppler (apt install poppler-utils / brew install poppler).

    3. Google Drive optional

    Connect Google to save approved PDFs to your Drive, open a resume as a Google Doc to edit by hand, and bring your edits back. The app asks only for access to files it creates itself.

    Create your Google OAuth client (about 5 minutes, free)

    Google doesn't allow an open source app to ship one shared client secret, so you make your own. It stays on this computer.

    1. Open Google Cloud: new project and create a project (any name, for example "Resume Tailor").
    2. Turn on the Google Drive API for that project (press Enable).
    3. Open Google Auth Platform, press Get started, give the app a name and your email, pick Audience "External", and finish.
    4. Under Audience, add your own Google address as a test user.
    5. Under Clients, press Create client, choose Application type "Desktop app", and create it.
    6. Copy the Client ID and Client secret into the boxes below (or download the JSON and paste its contents), then press Save.
    7. Press Connect Google and approve. While the app is in testing, Google shows an "unverified app" screen: that is your own app, so press Continue.

    4. Your profile

    A profile is a folder: your base resume (.docx), facts.md (every fact Claude may use; a number that is in neither the base nor the fact bank fails the honesty check), known_skills.txt and rules.toml (what the checks enforce). See docs/PROFILE.md for the format.
